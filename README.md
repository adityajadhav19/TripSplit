# TripSplit

**Split expenses, not friendships.**

TripSplit is a web application for managing shared expenses with friends and travel groups. Create a group, track who paid, split costs among participants, and calculate who owes whom.

## Features

- **Group Management** — Create and join groups securely.
- **Expense Tracking** — Record expenses, payers, and participants.
- **Expense Splitting** — Track each participant's share.
- **Settlement Summary** — Calculate balances between group members.
- **Secure Access** — Password-protected groups and session-based authentication.
- **Responsive Design** — Works across desktop and mobile devices.

## Tech Stack

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **Backend:** Next.js API Routes
- **Database:** PostgreSQL
- **ORM:** Prisma
- **Authentication:** Jose (JWT), bcryptjs
