TripSplit

Split expenses. Share costs. Settle up.

TripSplit is a group expense-sharing application that makes it easy to track shared expenses, calculate who owes whom, and simplify settlements during trips and group activities.

Live Demo

"Open TripSplit" (https://tripsplit-split-expence.vercel.app/)

Features

- Create Groups – Create expense-sharing groups and invite others to join.
- Group Access – Join existing groups using group credentials.
- Expense Tracking – Add and manage expenses within a group.
- Expense Ownership – Group creators and expense creators have permission to edit or delete their respective expenses.
- Expense Splitting – Automatically distribute expenses among selected group members.
- Settlement Calculation – Calculate balances and determine who owes whom.
- Persistent Sessions – Sliding sessions help keep users logged in.
- Responsive Interface – Access TripSplit from desktop and mobile devices.

Tech Stack

- Frontend: Next.js, React, TypeScript
- Styling: Tailwind CSS
- Backend: Next.js API Routes
- Database: PostgreSQL
- ORM: Prisma
- Deployment: Vercel
